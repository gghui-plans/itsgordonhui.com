# ItsGordonHui.com

The source for Gordon Hui's independent professional website.

## Website

The site presents selected transportation planning and parking management work, professional perspectives, and contact information. Project pages identify the relevant client, Gordon's employer, and his confirmed responsibilities.

## Content and media rules

- Do not publish confidential, proprietary, or unpublished client material.
- Do not use Burnside figures, maps, charts, diagrams, photographs, slides, or other visual assets.
- Use non-Burnside media only after reuse permission is confirmed.
- Do not list or credit individual project-team members in the four launch case studies.
- Keep CVs, working documents, permission records, and credentials outside this public repository.

## Local development

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

The site is configured for GitHub Pages and the custom domain `itsgordonhui.com`. DNS changes are handled separately after the local site and GitHub Pages deployment are approved.
